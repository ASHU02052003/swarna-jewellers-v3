# Swarna Jewellers — React + Vite

Clean React + Vite + TypeScript jewellery website for Swarna Jewellers.

## Business details
- **Location:** Bank of Belonia, South Tripura
- **Landmark:** Opposite Punjab National Bank (PNB)
- **Hours:** Mon–Sat · 10:30 AM–8:00 PM
- **Phone / WhatsApp:** +91 96120 91964

## Run
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

The design direction can take inspiration from the information architecture and jewellery-commerce patterns used by Kisna. For actual Kisna product photography, logos, names, descriptions or other brand assets, use only assets supplied/approved by Kisna or otherwise licensed for Swarna Jewellers. Do not scrape and republish their website images without permission.
